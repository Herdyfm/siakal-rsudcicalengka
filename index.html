Pengaturan Koneksi Supabase Database

Aplikasi ini dapat dihubungkan langsung ke **Supabase** secara gratis. Isikan **Project URL** dan **Anon Key** dari dashboard Supabase Anda.

Skrip DDL SQL untuk Supabase (Salin ke SQL Editor Supabase):

CREATE TABLE assets (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  code TEXT UNIQUE NOT NULL,
  name TEXT NOT NULL,
  category TEXT NOT NULL,
  location TEXT NOT NULL,
  brand TEXT,
  serial TEXT,
  condition TEXT DEFAULT 'Baik',
  interval_months INT DEFAULT 12,
  last_calibrated DATE,
  due_date DATE NOT NULL,
  notes TEXT,
  created_at TIMESTAMPTZ DEFAULT now()
);

-- Buka akses publik/anonim untuk laporan & admin CRUD (atau sesuaikan RLS)
ALTER TABLE assets ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Public Read Access" ON assets FOR SELECT USING (true);
CREATE POLICY "Public Write Access" ON assets FOR ALL USING (true);

Panduan Hosting Gratis di GitHub Pages

  1. Buat Repositori Baru di GitHub:

    Buka GitHub.com, pilih New Repository, beri nama misal sima-rsud, lalu set ke Public.

  2. Simpan File Ini Sebagai index.html:

    Simpan semua file kode HTML tunggal ini dengan nama file persis index.html.

  3. Upload File ke GitHub:

    Klik Upload an existing file di halaman repositori GitHub Anda, upload file index.html, lalu klik Commit changes.

  4. Aktifkan GitHub Pages:

    Masuk ke menu Settings → Pages. Pada bagian Build and deployment / Branch, pilih branch main (root), lalu klik Save.

  5. Aplikasi Siap Diakses!

    Website SIMA-RSUD Anda akan aktif dalam 1-2 menit pada URL: https://username.github.io/sima-rsud/
